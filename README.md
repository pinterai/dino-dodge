# Dino Dodge Scratch Game 🦖 <br>
This is my Harvard CS50x Week 0 Scratch project. You and your mirror dinosaur who moves invertedly to you must dodge falling meteors whilst trying not to get hit. 
To win you must eliminate 10 meteors using your cheesepuff dispenser, and avoid getting hit more than 5 times. 

## How to play 🎮
- Download the .sb3 file attatched.
- Open [Scratch](https://scratch.mit.edu)
- Click file -> Load from Computer
- Open the .sb3 file on Scratch & play!

## Features 📝
- Event driven programming (when start clicked...)
- Loops
- Conditionals
- Broadcast messages
- Custom blocks
- Cloning meteors
